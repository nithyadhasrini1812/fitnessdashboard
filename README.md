🏋️ Fitness Dashboard

📌 Project Overview

This is an interactive Fitness Dashboard created using Power BI to analyze and visualize fitness and gym-related data.

🎓 Training & Learning

This dashboard was created as part of a 3-week Power BI training program. During the training, I learned the fundamentals of data analytics, data visualization, dashboard creation, and interactive reporting using Power BI.

🛠️ Tools & Technologies

- Power BI
- Microsoft Excel
- Data Analytics
- Data Visualization

📊 Dashboard Features

- KPI cards
- BMI analysis
- Age-wise analysis
- Gender-wise analysis
- Fitness and workout analysis
- Interactive slicers
- Charts and visualizations

🎯 Objective

To transform raw fitness data into meaningful insights through an interactive and easy-to-understand dashboard.
